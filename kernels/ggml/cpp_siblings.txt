# GPU-only kernels and their cpp siblings, one pair per line:
#   <kernel> <sibling>
# slangc -target cpp rejects GroupMemoryBarrierWithGroupSync (E36107): its
# per-thread dispatch runs a group's threads one after another. A kernel
# that shares group memory therefore has a sibling (lean/Ggml, e.g.
# MulMatSerial) with the same params words, the same thread-group size and
# the same grid, computing every output as the same sum in the same order
# with no group memory. Both are in kernels.txt and both compile to SPIR-V;
# gen.sh emits cpp for the sibling only (and the table check requires the
# pair's thread-group sizes to match), and the L2 harness runs the
# sibling's cpp wherever a packer chose the kernel.
